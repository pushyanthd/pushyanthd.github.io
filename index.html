01Document intelligence

Document Intelligence Workbench

A local invoice workspace that connects extracted fields to page evidence. Reviewers can correct a version, approve it, and export the exact approved record.

  • Python
  • SQLite
  • Docker
  • OCR
View repositoryRead project notes
Engineering details

An experimental local invoice workflow with isolated parsing, evidence-linked review, auditable revisions, and approved exports. Paired tests cover 180 invoices and 100 receipts; rules remain the default because the local model regressed on invoice headers and exact rows. A six-case author pilot completed, with exact required headers on 5/6 cases and exact rows on 19/20. This does not establish production financial correctness or broad vendor accuracy.

Experimental v0.1.0 candidate · publication pending
02Recommendation & ranking

CPU Recommendation Service

A CPU-only movie recommendation API with chronological evaluation, automatic model selection, cold-start fallback, and verified rollback.

  • FastAPI
  • NumPy / SciPy
  • CPU ALS
  • Docker
View repositoryRead project notes
Engineering details

Compared popularity, item similarity, and ALS for 1,188 MovieLens users. Item similarity improved final NDCG@10 by 11.97%, but its 3.41% validation gain missed the frozen 10% objective, so popularity remains selected. The selected snapshot served 5,000 HTTP requests with zero failures and 11.65 ms client P95 on Apple M1. This is a local benchmark/demo, not evidence of online impact or production security; independent scanning still reports a HIGH zlib advisory.

v1.0.0 prepared · publication pending
03Retrieval & evaluation

RAG Evaluation Platform

A reproducible comparison of sparse, dense, hybrid, and reranked retrieval, with confidence intervals and regression gates to make quality changes measurable.

  • FastAPI
  • pgvector
  • BEIR
  • OpenTelemetry
View repositoryRead project notes
Engineering details

Full BEIR test sets across SciFact, NFCorpus, and FiQA show that the best nDCG@10 point estimate changes by domain: dense retrieval leads on SciFact and FiQA, while reranked hybrid leads on NFCorpus. The repo also includes confidence intervals, paired comparisons, a regression gate, cited-answer evaluation, and observability. Generated-answer scores are benchmark results, not proof of judge validity or general factual accuracy.

Published benchmark reports · experimental answer evaluation
04ML infrastructure

Real-Time ML Platform

NYC taxi-duration modeling with validated data, point-in-time features, guarded model promotion, and online prediction serving on Kubernetes.

  • MLflow
  • Kubernetes
  • FastAPI
  • Redpanda
View repositoryRead project notes
Engineering details

The v0.1.0 candidate packages reproducible NYC taxi-duration training and guarded online serving. On the fixed April holdout, the approved model reached 187.18 s MAE, 25.78% below the declared baseline. Local kind testing served 10,000 requests at 100 requests/s with 7.99 ms client P95 and no errors or dropped requests. These results use one local kind node; completed-trip distance makes this unsuitable as a pre-trip ETA claim.

v0.1.0 candidate · publication pending
05Agent security

Secure Agent Platform

A resumable agent evaluation platform with application-owned tool boundaries, scoped permissions, reviewable actions, and a frozen prompt-injection benchmark.

  • Agent architecture
  • Scoped permissions
  • Evaluation design
View repositoryRead project notes
Engineering details

The completed 400-trial evaluation measured clean-task success at 104/160 for the defended system; two defended attacks remained unresolved and the release gate failed. A later eight-trial utility pilot was also rejected. The repository preserves the failed results and limitations rather than treating the platform as release-ready.

400-trial evaluation complete · release gate failed
